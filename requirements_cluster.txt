# --
# requirements for training-only runs on a GPU cluster (e.g. SLURM)
#
# This is requirements_pytorch.txt minus the packages a headless training
# node does not need and that pull in the ai-edge / litert stack (which does
# not install on the cluster):
#   - litert-torch             -> tflite export; depends on the ai-edge stack.
#                                 Without it no .tflite is produced; the .pth
#                                 model + its val ACC/AUC are still logged.
#                                 Export + int8 quantization are done locally.
#   - ai-edge-quantizer-nightly-> int8 quantization (post-training, no GPU);
#                                 run locally (BIODCASE_SKIP_QUANTIZATION=1).
#   - PyQt6                    -> interactive matplotlib backend only; the
#                                 cluster saves PNGs via Agg (MPLBACKEND=Agg).
#   - docker                   -> ESP32 deployment toolchain, skipped here.
#
# The cluster run therefore does: train (distillation) -> evaluate the .pth
# model -> log val metrics. Pull the .pth back and run tflite export +
# quantization locally on the candidates worth deploying.

jinja2
